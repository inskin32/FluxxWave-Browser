# FluxxWave-Browser
FluxxWave Browser is a pimarly privacy-focused browser, it has DuckDuckGo and Wave Search as default search engines. DuckDuckGo to prevent any kind of tracking
and Wave search (developed by FluxxWave Project™ and UNP™[UNP=Unknown Net Project]) to browse inside the THN net (a hidden net which i already made a repository, hyperlink: https://github.com/inskin32/THN) for more information, visit the FluxxWave Project website at http://www.inskinarchive.it/fwproject.html
