# FluxxWave-Browser
FluxxWave Browser is a pimarly privacy-focused browser, it has DuckDuckGo and Wave Search as default search engines. DuckDuckGo to prevent any kind of tracking
and Wave search (developed by TBP [THN Browsing Project]) to browse inside the THN (a hidden net which i already made a repository) for more information,
visit the TBP website at http://inskinarchivearchive.it/tbp.html.
